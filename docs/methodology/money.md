# 理财与投资

> 对“用ai入门一个领域”的尝试

## 基础认知

**① 理财 ≠ 投资。**
理财是在安排钱在现在、未来和风险之间的分配，应对通胀。

**② 钱的用途和使用时间，先于收益率。**
先问“什么时候要用”，再问“买什么”。

**③ 收益、风险、流动性之间存在取舍。**
不要只看到“收益高不高”，而要养成问“我为这个收益承担了什么”的习惯。

## 第二课 

- **年化：把收益放到统一时间尺度比较。**
    - 72法则: **72 ÷ 年化收益率 (%) ≈ 翻倍所需年数**
- **复利：收益继续产生收益，时间会放大效果。**
- **看到收益率，永远顺手问一句：这个收益是承担什么风险换来的？**

## 第三课｜投资中的风险

### ① 波动风险

资产价格会涨跌，尤其在**短期需要用钱**时非常重要。

> 高波动资产 + 短期刚性资金需求 = 危险组合

### ② 永久损失风险

资产跌了不一定意味着永久亏损，但有些资产可能**真的再也涨不回来**，甚至归零。

### ③ 流动性风险

> **有资产，但需要钱的时候无法及时变现。**

因此短期需要使用的钱，不仅要求安全，也要求有足够的**流动性**。

### ④ 通胀风险

钱的数字没有减少，**购买力也可能下降**。短期现金很稳定，但长期可能受到通胀侵蚀。

!!! note "两个最重要的认识"

    **1. 风险不能简单理解成“会不会亏”。**

    更应该问：

    > **可能发生什么坏事？如果发生，我能否承受？**

    **2. 风险与个人情况有关。**

    同样是股票下跌 30%：

    * 三个月后必须用的钱 → 可能造成严重问题
    * 十年不用的钱 → 可能是可以承受的短期波动

    所以：

    > **资产有风险 ≠ 这项投资不合理。**
